memory over MCP

Connect an agent

Anyone with this URL can read and write this memory.

Agent
claude mcp add --transport http memory
codex mcp add memory --url
pi mcp add memory --url

Then start a new session and ask the agent to remember something.

Memories

Only the top-level lines enter the agent's context. They are exactly what memory_wake returns, oldest first. A #a-b line is one summary of every note in its range. Opening it here shows what memory_zoom returns, and the agent sees those lines only when it zooms in itself.

Done testing?

  1. Destroy this memory. Every note and summary is deleted for good.

  2. Remove the server from your agent.

    claude mcp remove memory
    codex mcp remove memory
    pi mcp remove memory

    Run it in the directory where you ran claude mcp add. Claude Code adds a server to the current project by default.

The URL keeps working after a destroy. If an agent or this page uses it again, a new, empty memory starts there.
